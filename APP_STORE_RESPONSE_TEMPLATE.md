# Réponse à l'équipe d'examen de l'App Store

## 📝 Message à envoyer dans App Store Connect

**Copiez et collez ce message dans votre réponse dans App Store Connect:**

---

**Objet : Résolution - Liens vers les Conditions d'Utilisation Ajoutés**

Bonjour,

Nous vous remercions pour vos commentaires concernant la directive 3.1.2.

Nous avons maintenant mis à jour l'application et les métadonnées pour inclure des liens fonctionnels vers nos Conditions d'Utilisation (CLUF) et notre Politique de Confidentialité.

**Dans l'application :**
- Nous avons configuré notre écran d'abonnement (paywall) pour afficher les liens légaux dans le pied de page
- Le lien vers les Conditions d'Utilisation est maintenant visible pendant le processus d'achat
- Le lien vers la Politique de Confidentialité est également inclus

**Dans les métadonnées de l'App Store :**
- Nous avons ajouté les liens vers nos Conditions d'Utilisation et notre Politique de Confidentialité dans la description de l'application

**URLs légales :**
- Conditions d'Utilisation : https://tawfik-software.github.io/focusapp/terms.html
- Politique de Confidentialité : https://tawfik-software.github.io/focusapp/privacy-policy.html

Les deux liens sont fonctionnels et accessibles. Nous avons testé le processus d'abonnement sur iPad Air et iPhone pour assurer la conformité.

N'hésitez pas à nous contacter si vous avez besoin d'informations supplémentaires.

Cordialement,
L'équipe Focus App

---

## 📍 Où envoyer cette réponse

1. **Connectez-vous à App Store Connect**
   - Allez sur : https://appstoreconnect.apple.com
   - Connectez-vous avec vos identifiants

2. **Naviguez vers votre app**
   - Sélectionnez "focusapp" / "Ultra Focus Flow Study Timer"

3. **Accédez à la section Révision**
   - Cliquez sur l'onglet **"Version de l'App"**
   - Trouvez la version rejetée (1.0.1)

4. **Répondez à l'équipe d'examen**
   - Cherchez le message de rejet
   - Cliquez sur **"Répondre"** ou **"Reply"**
   - Collez le message ci-dessus (en français ou en anglais)
   - Cliquez sur **"Envoyer"**
